# Assets

Place the following files here before building:

- `icon.png` — 1024×1024 px app icon (dark background, brand mark)
- `splash.png` — 1242×2436 px splash screen
- `adaptive-icon.png` — 1024×1024 px Android adaptive icon foreground
- `favicon.png` — 48×48 px web favicon

Color theme: background #0a0a0f (near-black), brand accent #22c55e (tactical green).
